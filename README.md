# Mafia Host

Локальный инструмент ведущего спортивной мафии: таймер, 10 игроков, фолы, голосование, роли, баллы, заметки, история игр и общая таблица.

## Запуск

Дважды нажмите `start.command`. Запустится локальный сервер, после чего сайт автоматически откроется по адресу [http://127.0.0.1:8000](http://127.0.0.1:8000).

Если macOS при первом запуске блокирует файл, нажмите по `start.command` правой кнопкой, выберите `Открыть` и подтвердите запуск. Также сайт можно запустить из Terminal:

```sh
python3 server.py
```

После обновления приложения перезапустите открытый сервер, чтобы новые правила интерфейса и SQLite API совпадали. При несовместимой старой версии интерфейс покажет просьбу снова запустить `start.command`.

Окно Terminal должно оставаться открытым во время работы. Для остановки сервера нажмите `Ctrl+C`. Интернет и установка библиотек не нужны — используются только встроенные возможности Python.

Верхняя навигация разделяет приложение на три экрана: `Игра`, `История` и `Общая таблица`. Переходы работают без перезагрузки страницы.

Клавиша `Space` на экране игры каждый раз обнуляет таймер и запускает новый отсчёт. Кнопка `Сбросить` обнуляет и останавливает его. Когда курсор находится в поле ввода, пробел вводится как обычный символ. На экранах истории и общей таблицы `Space` не управляет скрытым таймером.

Кнопка `Рассадить случайно` перемешивает десять заполненных никнеймов по игровым слотам. Если заполнены не все ники, сайт покажет, сколько осталось добавить.

Кнопка `Выставить` добавляет номер игрока в текущий круг голосования. Повторный клик снимает выставление. У каждого кандидата раскрывается компактный список `Голоса`, где можно отметить номера проголосовавших; один игрок учитывается только у одного кандидата в рамках этапа. В раскрывающемся блоке `Переголосование` выбираются два или более кандидата для отдельного этапа с пустыми голосами. Блок `Исход голосования` отмечает выставленных игроков, покинувших стол, либо вариант `× Никто`, если после попила или переголосования стол никто не покинул. Если создано переголосование, исход выбирается только на его последнем этапе, а у исходного голосования лишний блок скрывается. `Следующий круг` создаёт новый обычный круг. `Сбросить круги` удаляет все выставления и возвращает пустой круг 0.

Игрок, убитый в ночь N, ещё участвует в предыдущем круге N−1 и больше не может голосовать начиная с круга N. Поэтому в нулевом круге всегда доступны все 10 игроков, а ПУ становится недоступен только в круге 1. Игрок, отмеченный покинувшим стол в исходе голосования, не может голосовать на последующих этапах. Его номер остаётся видимым в списке голосующих, но становится недоступным.

Ночи находятся прямо на игровом экране: в последовательных ячейках `Н1`, `Н2` и далее указывается номер цели или ставится `×` при промахе. Кнопка `+ Ночь` добавляет следующую ячейку. Цель первой ночи автоматически становится ПУ и выделяется синим в таблице; при промахе в первую ночь ПУ нет, а поля ЛХ очищаются и блокируются. Рядом находятся три компактных поля ЛХ.

Кнопка `Новая игра` сохраняет текущую рассадку, но очищает роли, ПУ, обычные и технические фолы, дополнительные баллы, заметки, победителя, таймер, ночи, ЛХ и все круги голосования.

Текущее состояние игры сохраняется в браузере автоматически. После перезагрузки страницы восстанавливаются игроки, роли, ПУ, обычные и технические фолы, доп. баллы, заметки, победитель, круги и исходы голосования, ночи, промахи, ЛХ и таймер.

## Баллы и сохранение

Выберите роль игрока из списка: `Мирный`, `Шериф`, `Мафия` или `Дон`. Роли отмечены разными цветами и не вводятся вручную. После выбора победителя балл `1` или `0` рассчитается автоматически. Дополнительный балл или штраф вводится вручную, сумма рассчитывается сайтом. У игрока может быть до двух техфолов; каждый автоматически уменьшает итог на `0.3`. Если среди трёх номеров ЛХ указаны два разных чёрных игрока (`Мафия` или `Дон`), ПУ автоматически получает `+0.5`; если три — `+0.8`. Ручной доп/штраф, техфолы, ЛХ и зарезервированный балл CI хранятся отдельно, а итог складывается из всех компонентов. Формула CI будет добавлена позже; пока его значение равно нулю.

Кнопка `Сохранить игру` записывает результат в SQLite-базу `data/mafia-host.sqlite3`. Очистка истории и данных браузера не удаляет эту базу. Каждая игра получает стабильный ID по результату, поэтому повторное сохранение тех же данных не создаёт дубль. Сохранённые игры доступны на экране `История`: в таблице показаны столбцы `№`, `Ник`, `Роль` и `Балл`. В строке виден только общий балл, а его ненулевые составляющие раскрываются при наведении, фокусе или нажатии. ПУ также выделен синим; кнопка `Удалить` удаляет выбранную запись из SQLite.

Если игра была сохранена старой версией запущенного сервера без отметки ПУ, приложение восстанавливает её из текущей игры только при точном совпадении результата. Для остальных старых записей ПУ нельзя определить автоматически, потому что ночи раньше не сохранялись в архиве.

При первом запуске сервер автоматически переносит старые CSV из папки `games`.

Если игры существовали только в старой браузерной IndexedDB и не появились в SQLite, оставьте сервер запущенным и откройте `legacy-recovery.html` напрямую через Finder. Страница сравнит старую базу с SQLite по ID, дате и времени и предложит перенести только отсутствующие записи. Повторный запуск не создаёт дубли.

Для резервной копии остановите сервер и скопируйте файл `data/mafia-host.sqlite3` в безопасное место. Чтобы восстановить данные, верните этот файл в ту же папку при остановленном сервере.

Экран `Общая таблица` объединяет сохранённые игры по никнейму и показывает сумму всех баллов, чистую сумму дополнительных баллов с учётом ручных штрафов и техфолов, положительные допы, отрицательные штрафы, число игр и средний балл. Игры можно ограничить включительным интервалом даты и времени. Игроки сортируются по сумме всех баллов.

У каждой сохранённой игры есть кнопка `Изменить`. В окне редактирования видны ЛХ первого убиенного и заметки всех игроков. Можно поменять дату, время, победителя, никнеймы, роли, основные и дополнительные баллы, техфолы и заметки. Итоговые суммы, ID игры, история и рейтинг пересчитываются после сохранения изменений.

## Разработка

Клиент написан на нативных ES-модулях без сборщика и внешних зависимостей. `app.js` только связывает контроллеры; бизнес-правила находятся в `js/domain.js`, доступ к данным — в `js/storage.js`, а экраны и игровые подсистемы разнесены по отдельным модулям.

Проверки:

```sh
npm test
python3 -m unittest discover -s test -p '*_test.py'
```

Правила и карта проекта для Codex находятся в `AGENTS.md`.
