# Mafia Host

Локальный инструмент ведущего спортивной мафии: таймер, 10 игроков, фолы, голосование, роли, баллы, заметки, история игр и общая таблица.

## Запуск

Дважды нажмите `start.command`. Запустится локальный сервер, после чего сайт автоматически откроется по адресу [http://127.0.0.1:8000](http://127.0.0.1:8000).

Если macOS при первом запуске блокирует файл, нажмите по `start.command` правой кнопкой, выберите `Открыть` и подтвердите запуск. Также сайт можно запустить из Terminal:

```sh
cd /Users/voprosovnety/Projects/mafia-host
python3 server.py
```

Окно Terminal должно оставаться открытым во время работы. Для остановки сервера нажмите `Ctrl+C`. Интернет и установка библиотек не нужны — используются только встроенные возможности Python.

Верхняя навигация разделяет приложение на три экрана: `Игра`, `История` и `Общая таблица`. Переходы работают без перезагрузки страницы.

Клавиша `Space` на экране игры каждый раз обнуляет таймер и запускает новый отсчёт. Кнопка `Сбросить` обнуляет и останавливает его. Когда курсор находится в поле ввода, пробел вводится как обычный символ. На экранах истории и общей таблицы `Space` не управляет скрытым таймером.

Кнопка `Выставить` добавляет номер игрока в текущий круг голосования. Повторный клик снимает выставление. `Следующий круг` сохраняет текущие номера и создаёт новый круг. `Сбросить круги` удаляет все выставления и возвращает пустой круг 0.

Текущее состояние игры сохраняется в браузере автоматически. После перезагрузки страницы восстанавливаются игроки, роли, фолы, доп. баллы, заметки, победитель, круги голосования и таймер.

## Баллы и сохранение

Выберите роль игрока из списка: `Мирный`, `Шериф`, `Мафия` или `Дон`. Роли отмечены разными цветами и не вводятся вручную. После выбора победителя балл `1` или `0` рассчитается автоматически. Дополнительный балл вводится вручную, сумма рассчитывается сайтом.

Кнопка `Сохранить игру` записывает результат в SQLite-базу `data/mafia-host.sqlite3`. Очистка истории и данных браузера не удаляет эту базу. Каждая игра получает стабильный ID по результату, поэтому повторное сохранение тех же данных не создаёт дубль. Сохранённые игры доступны на экране `История`, а кнопка `Удалить` удаляет выбранную запись из SQLite.

При первом запуске сервер автоматически переносит старые CSV из папки `games`. Если какие-то игры существовали только в старой браузерной IndexedDB и не появились в истории, оставьте сервер запущенным и один раз откройте `index.html` напрямую через Finder: страница перенесёт доступные ей старые записи в SQLite.

Для резервной копии остановите сервер и скопируйте файл `data/mafia-host.sqlite3` в безопасное место. Чтобы восстановить данные, верните этот файл в ту же папку при остановленном сервере.

Экран `Общая таблица` объединяет сохранённые игры по никнейму и показывает сумму всех баллов, чистую сумму дополнительных баллов с учётом штрафов, положительные допы, отрицательные штрафы, число игр и средний балл. Игры можно ограничить включительным интервалом даты и времени. Игроки сортируются по сумме всех баллов.

У каждой сохранённой игры есть кнопка `Изменить`. В окне редактирования можно поменять дату, время, победителя, никнеймы, роли, основные и дополнительные баллы. Итоговые суммы, ID игры, история и рейтинг пересчитываются после сохранения изменений.

## Разработка

Клиент написан на нативных ES-модулях без сборщика и внешних зависимостей. `app.js` только связывает контроллеры; бизнес-правила находятся в `js/domain.js`, доступ к данным — в `js/storage.js`, а экраны и игровые подсистемы разнесены по отдельным модулям.

Проверки:

```sh
npm test
python3 -m unittest discover -s test -p '*_test.py'
```

Правила и карта проекта для Codex находятся в `AGENTS.md`.
