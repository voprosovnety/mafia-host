# Mafia Host

## Развёртывание

Требуется Python 3. Внешние Python-зависимости и подключение к интернету не нужны.

Запуск в macOS: дважды нажмите `start.command`. Сервер откроет приложение по адресу [http://127.0.0.1:8000](http://127.0.0.1:8000).

Либо запустите из терминала в корне проекта:

```sh
python3 server.py
```

Для запуска без автоматического открытия браузера:

```sh
python3 server.py --no-browser
```

По умолчанию сервер слушает только `127.0.0.1:8000`. При необходимости можно указать другой адрес, порт и путь к базе:

```sh
python3 server.py --host 127.0.0.1 --port 8001 --database /путь/к/mafia-host.sqlite3
```

Данные хранятся локально в `data/mafia-host.sqlite3`. Для резервной копии остановите сервер и скопируйте этот файл; для восстановления верните его на место также при остановленном сервере. Не добавляйте базу данных и её WAL/SHM-файлы в Git.

Сервер останавливается сочетанием `Ctrl+C` в окне терминала.

## Разработка

Для JavaScript-проверок требуется Node.js. У проекта нет npm-зависимостей, поэтому `npm install` не нужен.

Запуск в режиме разработки:

```sh
python3 server.py --no-browser
```

После изменения серверного кода перезапустите сервер. Клиентские файлы достаточно обновить в браузере.

Проверки:

```sh
npm test
python3 -m unittest discover -s test -p '*_test.py'
node --check app.js
for file in js/*.js; do node --check "$file"; done
python3 -m py_compile server.py backend/*.py
zsh -n start.command
```
